# TOK - Ultimate 3D Edition

Benvenuto nel repository ufficiale della nuova versione completamente ridisegnata da zero del gioco da tavolo **TOK (Tock)**.

## Caratteristiche Principali
- **UI Dark & Glassmorphism**: Interfaccia moderna e immersiva in stile cyberpunk/futuristico.
- **Tabellone 3D Volumetrico**: Prospettiva reale e spessore visivo avanzato con CSS 3D Transforms.
- **Pedine e Carte 3D**: Elementi di gioco volumetrici, interattivi con animazioni ed effetti di luce dinamici.
- **Motore di Gioco Intatto**: Conserva tutte le regole originali (gestione turni, carte speciali come Assi, Re, Jack, 7, blocco e squadre 2 vs 2).

## Come Avviare
Basta clonare il repository o scaricare il file `index.html` e aprirlo direttamente in qualsiasi browser web moderno.
